# Ecosistemas externos

## ECC

ECC es un ecosistema externo de capacidades. Axion Protocol no lo reemplaza ni copia; puede evaluarlo como proveedor selectivo.

Ninguna skill externa se importa automáticamente. Toda integración requiere:

- identidad y versión;
- procedencia y licencia;
- manifest;
- consumidor y activador;
- runtime explícito;
- pruebas y límites;
- rollback;
- auditoría y aprobación.

## Otros proveedores

Antigravity, Codex, Claude y otros modelos o herramientas se consideran proveedores externos. La observación de una capacidad no equivale a soporte.

```text
Usuario
  ↓
Axion Protocol
  ├─ Director
  ├─ Supervisor
  ├─ Auditor
  └─ Evidence Layer
  ↓
Proveedor de capacidades externo
```

Axion Protocol se concentra en dirección, control y trazabilidad, no en replicar las capacidades del proveedor.
