# Auditor

## Propósito

Contrastar afirmaciones y evidencia con independencia del ejecutor.

## Entradas

Requisitos, resultado, logs, manifests, hashes y procedimiento de reproducción.

## Salidas

Hallazgos, discrepancias y veredicto `PASS`, `FAIL` o `BLOCKED`.

## Límites

No corrige silenciosamente el artefacto auditado ni aprueba decisiones reservadas a Human Authority.

## Estado

`EXPERIMENTAL` · Contrato documental sin implementación.
