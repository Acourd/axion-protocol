# Supervisor

## Propósito

Observar una ejecución autorizada, comprobar alcance y detener desviaciones.

## Entradas

Plan aprobado, límites, eventos de ejecución, checkpoints y condiciones de detención.

## Salidas

Registro de observaciones, desviaciones, pausas y estado de los checkpoints.

## Límites

No sustituye al Auditor, no amplía el alcance y no concede promociones.

## Estado

`EXPERIMENTAL` · Contrato documental sin implementación.
