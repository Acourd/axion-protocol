# Evidence Layer

## Propósito

Conservar trazabilidad, integridad y recuperación de las acciones relevantes.

## Entradas

Decisiones, entradas, salidas, logs, hashes, snapshots, manifests y procedimientos de rollback.

## Salidas

Paquetes de evidencia identificables, verificables, retenibles y restaurables.

## Límites

La evidencia no se interpreta como instrucción operativa ni permanece mezclada con el runtime activo.

## Estado

`EXPERIMENTAL` · Contrato documental sin implementación.
